# 나노바나나 제미나이 워터마크 지우개 (NanoBanana Watermark Cleaner)

구글 제미나이(Google Gemini / Imagen) 기반 이미지 생성 시 우측 하단에 자동으로 합성되는 반투명 스파클(✦) 워터마크를 **수학적 역알파 블렌딩(Inverse Alpha Blending)** 연산으로 100% 원본 픽셀 수준으로 복원하는 웹 애플리케이션입니다.

## ✨ 주요 기능
- **100% 로컬 브라우저 처리**: 외부 서버로 이미지를 전송하지 않아 개인정보 및 보안상 안전합니다.
- **수학적 무손실 복원**: AI 추측 생성이 아닌 역알파 블렌딩 수식으로 투명도 값을 역계산해 선명도를 유지합니다.
- **간편한 입력**: 드래그 앤 드롭 파일 업로드 및 클립보드 붙여넣기(`Ctrl + V`) 지원
- **인터랙티브 슬라이더**: 제거 전(Before) / 제거 후(After) 실시간 비교 기능
- **저장 편의성**: 파일명 직접 지정, 브라우저 대화상자를 통한 `다른 이름으로 저장...`, 빠른 저장 및 다중 파일 ZIP 일괄 다운로드 지원
- **최신 프로필 지원**: Gemini 3.5+ (최신 V2) 및 이전 버전 (V1) 자동 감지
